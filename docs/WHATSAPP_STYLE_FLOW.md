# WhatsApp-Style Reporting Flow

## First-time reporter

1. Choose language.
2. Enter or confirm name.
3. Select Employee or Visitor.
4. Enter phone number.
5. Accept privacy notice.
6. Start hazard report.

## Returning reporter

1. System recognizes phone number.
2. System uses reporter preferred language.
3. Main menu appears:
   - Report hazard
   - Check report status
   - Get help
   - Change language

## Hazard reporting

1. Describe hazard in simple words.
2. Upload photo. Photo is mandatory.
3. Choose location or enter other location.
4. AI generates:
   - hazard summary
   - suggested category
   - urgency
   - immediate action
   - suggested owner department
5. Reporter accepts or corrects AI summary.
6. Report is submitted.
7. Report ID is shown.
8. EHS dashboard receives the case.

## Low-literacy support

Use short instructions:

- Type issue
- Send photo
- Choose location
- Check summary
- Submit

Use examples:

- Oil on floor
- Blocked walkway
- Broken cable
- Unsafe stacking
- Chemical without label

## Privacy rule

EHS can see reporter name and phone number.
Action owner cannot see reporter name or phone number.
